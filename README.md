This repository contains basic Java programs to understand fundamental programming concepts.

## Programs Included

evenodd.java – Checks whether a number is even or odd.

sum.java – Finds the sum of all elements in an array.

reverse.java – Reverses a given string.

swap.java – Swaps two numbers without using a third variable.

multiply.java – Prints the multiplication table of a given number using a loop.

## Concepts Covered

Conditional Statements

Arrays

Strings

Arithmetic Operations

Loops

## Language Used

Java

## Purpose

To practise basic Java programming concepts and improve problem-solving skills.
